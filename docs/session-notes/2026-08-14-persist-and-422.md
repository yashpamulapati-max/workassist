## 1. HTTP 422 “Unprocessable Content”

Studio (`assist.stage`, Claude Haiku, no host tools) answered “how to create a work order” correctly.
The AMS iframe failed the same prompt with **HTTP 422** even on **claude-haiku-4**.

Console (the real error):

```
POST https://agents.stage.trimble-ai.com/v2/agents/37242c15-…/runs
HTTP 422: body.context: List should have at most 10 items after validation, not 14
```

`runContext.context` is capped at **10 items** by the Agent Service. We had 14 (then 12).
Sonnet-5 vs Haiku was a red herring for this failure.

- `agile_assets_api` body/params are **JSON strings** (no `additionalProperties`).

  `trimble-assist.js?v=…` / `.css?v=…`. Bump `ASSET_VER` + the JSP query on each embed deploy.

## 3. Chat vanished on “take me to work order window”

`OnChangeCurrentWindow` sets `location.href` to a new `w_main.jsp?menu_id=…`. That **destroys** the
parent page, so the panel and iframe unmount. FAB came back closed; user had to reopen Previous
Conversations.

Shipped **2026-08-14** (`sessionStorage`, same tab):

| Key | Role |
| --- | --- |
| `ta-panel-open` | Re-open the panel after the shell reload |
| `ta-panel-expanded` | Restore docked vs expanded |
| `ta-thread-id` | Passed as SDK `threadId` so the same thread resumes |

Events `thread:created` / `thread:changed` / `run:started` persist the thread id.
**X / FAB close** sets `ta-panel-open=0` — next window stays closed on purpose.

Parent **prompt chips and the Haiku hint** were removed (user request).
